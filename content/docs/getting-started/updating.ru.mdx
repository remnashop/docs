<Callout type="idea">
Перед обновлением ознакомьтесь с [историей изменений](/ru/docs/overview/whats-new) — там описаны изменения, которые могут потребовать ваших действий.
</Callout>

<Section title="Remnashop" description="Бот, панель управления и воркер" icon="Package">

```bash title="Обновление и перезапуск"
cd /opt/remnashop && docker compose pull && docker compose down && docker compose up -d && docker compose logs -f
```

```bash title="Очистка неиспользуемых образов"
docker image prune
```

</Section>
