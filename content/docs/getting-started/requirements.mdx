<Section title="Version compatibility" description="Remnawave and web cabinet versions for each Remnashop release" icon="Network">

| Remnashop         | Remnawave         | Web cabinet |
| ----------------- | ----------------- | ----------- |
| `1.0.0`           | `3.x.x`           | `1.0.0`     |
| `0.7.4` – `0.8.2` | `2.7.x`           | —           |
| `0.7.0` – `0.7.3` | `2.6.x`           | —           |
| `0.6.6`           | `2.3.2` – `2.5.7` | —           |

</Section>

<Section title="Remnashop server" description="Minimum and recommended specs" icon="Cpu">

* **OS**: Ubuntu or Debian
* **RAM**: 2 GB minimum, 4 GB recommended
* **CPU**: 2 cores minimum, 4 recommended
* **SSD**: 20 GB or more

<Callout type="warn">
If Remnashop runs on the same server as the Remnawave panel, the requirements add up: add the [panel's requirements](https://docs.rw/install/requirements/) to these. The minimum for both is 4 GB RAM, 4 CPU cores and 40 GB SSD.
</Callout>

</Section>

<Section title="Web cabinet server" description="Minimum specs" icon="Globe">

* **OS**: Ubuntu or Debian
* **RAM**: 512 MB minimum
* **CPU**: 1 core minimum
* **SSD**: 5 GB or more

<Callout type="idea">
The web cabinet is a lightweight nginx container with static files and an API proxy, so it can run on the same server as Remnashop.
</Callout>

</Section>

<Section title="Software" description="What to install before you start" icon="Container">

Remnashop needs Docker with the Docker Compose plugin.

```bash title="Install Docker with the official script"
sudo curl -fsSL https://get.docker.com | sh
```

</Section>
