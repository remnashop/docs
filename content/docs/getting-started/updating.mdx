<Callout type="idea">
Before updating, check the [changelog](/docs/overview/whats-new) for changes that may need action on your side.
</Callout>

<Section title="Remnashop" description="Bot, dashboard and worker" icon="Package">

```bash title="Update and restart"
cd /opt/remnashop && docker compose pull && docker compose down && docker compose up -d && docker compose logs -f
```

```bash title="Clean unused images"
docker image prune
```

</Section>

<Section title="Web cabinet" description="The user cabinet in the browser" icon="Globe">

```bash title="Update and restart"
cd /opt/remnashop/cabinet && docker compose pull && docker compose down && docker compose up -d && docker compose logs -f
```

</Section>
