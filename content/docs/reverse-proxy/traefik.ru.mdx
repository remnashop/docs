В этом руководстве мы используем Traefik в качестве обратного прокси для доступа к Remnashop. Мы направим доменное имя на сервер и настроим Traefik — сертификаты Traefik выпустит самостоятельно через Let’s Encrypt.

<Callout type="warn">
Для продолжения вам необходимо иметь зарегистрированное доменное имя.
</Callout>

<Section title="Способ установки" description="Где работает Remnashop относительно панели Remnawave" icon="Split">

<MethodSwitch same="На одном сервере" separate="На разных серверах" />

<Method only="same">

Traefik работает на том же сервере, что и панель Remnawave.

<Callout type="error">
Traefik уже должен быть установлен и настроен на сервере с панелью Remnawave и остальными компонентами.
</Callout>

</Method>

<Method only="separate">

Remnashop работает на отдельном сервере, без панели Remnawave рядом. Traefik ставится на этот же сервер.

<Callout type="error">
На этом сервере не должно быть установлено других обратных прокси.
</Callout>

</Method>

</Section>

<Section title="Направьте домен на сервер" description="A-запись для домена Remnashop" icon="Globe">

Узнайте IP-адрес вашего сервера. Лучше использовать статический IPv4-адрес.

Теперь направьте доменное имя на этот адрес, например `shop.domain.com` → `127.0.0.1`. Это можно сделать через DNS-провайдера (Cloudflare, Google Cloud и подобные) или через регистратора домена (Namecheap и подобные).

В Cloudflare нужно добавить запись A для IPv4 или AAAA для IPv6. Войдите в [аккаунт Cloudflare](https://dash.cloudflare.com/login) и выберите домен. В левой части страницы откройте `DNS`, затем `Records` и нажмите `Create record`.

Установите `Type` в значение `A`, а `Name` — в `@`.

<Callout type="idea">
Для поддомена впишите в поле `Name` его имя — например, `shop`.
</Callout>

Введите IP-адрес сервера в поле `IPv4 address` и нажмите `Save`. Обновление DNS-записей займёт некоторое время.

<Callout type="idea">
Жёлтое облако (домен проксируется через Cloudflare) и серое облако (не проксируется) работают по-разному. Если Cloudflare хорошо работает в вашем регионе, лучше проксировать домен через него.
</Callout>

![DNS-записи в Cloudflare](/images/cloudflare-dns.webp)

У других DNS-провайдеров интерфейс отличается, но процесс тот же.

</Section>

<Section title="Настройка Traefik" description="Статическая конфигурация и контейнер" icon="Settings">

<Method only="same">

Если Traefik уже настроен, переходите к следующему шагу: маршруты Remnashop добавляются отдельным файлом.

</Method>

<Method only="separate">

```bash title="Создание docker-compose.yml"
mkdir -p /opt/remnashop/traefik && cd /opt/remnashop/traefik && nano docker-compose.yml
```

```yaml title="docker-compose.yml"
services:
    traefik:
        image: traefik:v3
        container_name: traefik
        restart: unless-stopped
        security_opt:
            - no-new-privileges:true
        networks:
            - remnawave-network
        ports:
            - '0.0.0.0:80:80'
            - '0.0.0.0:443:443'
        environment:
            - TZ=UTC
        volumes:
            - ./traefik.yml:/traefik.yml:ro
            - ./letsencrypt:/letsencrypt
            - ./config:/config:ro
            - ./logs:/var/log/traefik
networks:
    remnawave-network:
        name: remnawave-network
        driver: bridge
        external: true
```

```bash title="Создание traefik.yml"
cd /opt/remnashop/traefik && nano traefik.yml
```

<Callout type="warn">
Замените `REPLACE_WITH_YOUR_EMAIL` на ваш адрес электронной почты.
</Callout>

```yaml title="traefik.yml"
api:
  dashboard: true
entryPoints:
  http:
    address: ":80"
    http:
      redirections:
        entryPoint:
          to: https
          scheme: https
  https:
    address: ":443"
providers:
  file:
    directory: /config
    watch: true
certificatesResolvers:
  letsencrypt:
    acme:
      email: REPLACE_WITH_YOUR_EMAIL
      storage: /letsencrypt/acme.json
      httpChallenge:
        entryPoint: http
log:
  level: "INFO"
  filePath: "/var/log/traefik/traefik.log"
accessLog:
  filePath: "/var/log/traefik/access.log"
```

</Method>

</Section>

<Section title="Маршруты Remnashop" description="Файл динамической конфигурации" icon="FileCode">

<Method only="same">

```bash title="Создание remnashop.yml"
cd /opt/remnawave/traefik/config && nano remnashop.yml
```

</Method>

<Method only="separate">

```bash title="Создание remnashop.yml"
mkdir -p /opt/remnashop/traefik/config && cd /opt/remnashop/traefik/config && nano remnashop.yml
```

</Method>

<Callout type="warn">
Замените `SHOP_DOMAIN` на домен Remnashop — значение `APP_DOMAIN`.
</Callout>

```yaml title="remnashop.yml"
http:
  routers:
    remnashop-telegram:
      rule: "Host(`SHOP_DOMAIN`) && Path(`/api/v1/telegram`)"
      entrypoints:
        - https
      tls:
        certResolver: letsencrypt
      service: remnashop-telegram
    remnashop:
      rule: "Host(`SHOP_DOMAIN`) && !Path(`/metrics`)"
      entrypoints:
        - https
      tls:
        certResolver: letsencrypt
      service: remnashop

  services:
    remnashop-telegram:
      loadBalancer:
        servers:
          - url: "http://remnashop-telegram:5001"
    remnashop:
      loadBalancer:
        servers:
          - url: "http://remnashop:5000"
```

<Callout type="idea">
Вебхуки Telegram уходят в контейнер `remnashop-telegram`, всё остальное — в `remnashop`. Подробнее — в [обзоре](/ru/docs/reverse-proxy).
</Callout>

</Section>

<Section title="Запуск Traefik" description="Применение конфигурации" icon="Play">

<Method only="same">

Traefik следит за папкой `config` и подхватит `remnashop.yml` сам — перезапуск не нужен.

</Method>

<Method only="separate">

```bash title="Запуск Traefik"
cd /opt/remnashop/traefik && docker compose up -d && docker compose logs -f -t
```

</Method>

</Section>

<Section title="Проверка" description="Панель управления открывается по домену" icon="CircleCheck">

</Section>
