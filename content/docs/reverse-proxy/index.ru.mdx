title: Обзор
icon: Route
---

Доступ к Remnashop идёт через обратный прокси: он терминирует TLS для вашего домена и передаёт запросы в контейнеры Remnashop.

<Callout type="warn">
Remnashop и его компоненты не поддерживают работу на суб-пути — например, `location /remnashop` или `location /remnawave`.
</Callout>

<Callout type="error">
SSH Port Forwarding не поддерживается. Используйте один из обратных прокси ниже.
</Callout>

<Callout type="idea">
Для продолжения вам необходимо иметь зарегистрированное доменное имя.
</Callout>

<Section title="Куда указывает прокси" description="Маршруты для домена из APP_DOMAIN" icon="Split">

Remnashop принимает запросы в двух контейнерах. Вебхуки Telegram идут в контейнер бота, всё остальное — в основной контейнер:

| Путь               | Контейнер                 | Что обслуживает                                              |
| ------------------ | ------------------------- | ------------------------------------------------------------ |
| `/api/v1/telegram` | `remnashop-telegram:5001` | Вебхуки Telegram                                             |
| `/`                | `remnashop:5000`      | Панель управления, API, вебхуки платёжных систем и Remnawave           |

<Callout type="idea">
Имена `remnashop` и `remnashop-telegram` доступны только внутри Docker-сети. Если прокси запущен не в Docker, используйте `127.0.0.1:5000` и `127.0.0.1:5001`.
</Callout>

</Section>
