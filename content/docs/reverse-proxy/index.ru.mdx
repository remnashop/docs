Доступ к Remnashop идёт через обратный прокси: он терминирует TLS для вашего домена и передаёт API бота в контейнер.

<Callout type="warn">
Remnashop и его компоненты не поддерживают работу на суб-пути — например, `location /remnashop` или `location /remnawave`.
</Callout>

<Callout type="error">
SSH Port Forwarding не поддерживается. Используйте один из обратных прокси ниже.
</Callout>

<Callout type="idea">
Для продолжения вам необходимо иметь зарегистрированное доменное имя.
</Callout>

***

## Куда указывает прокси

Обратный прокси должен указывать на контейнер с ботом по внутреннему адресу `remnashop:5000` — это Docker-имя сервиса из `docker-compose.yml`, доступное только внутри сети контейнеров.

Маршрут: `https://your-domain/api/v1` → `http://remnashop:5000`

***

## Выберите прокси

- [Caddy](/ru/docs/reverse-proxy/caddy) — лёгкий, выпускает SSL-сертификаты автоматически, почти без настройки
- [Nginx](/ru/docs/reverse-proxy/nginx) — популярный вариант, SSL-сертификаты выпускаются вручную
- [Traefik](/ru/docs/reverse-proxy/traefik) — проверенный временем, настраивается статическим и динамическим файлами
