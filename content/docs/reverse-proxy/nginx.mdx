In this guide we will use Nginx as a reverse proxy to reach Remnashop. We will point a domain name at the server, issue an SSL certificate and configure Nginx.

<Callout type="warn">
You need a registered domain name to continue.
</Callout>

***

## Point your domain to the server

Check your server's IP address. A static IPv4 address works best.

Now point your domain name at that address, for example `my-super-panel.com` → `193.122.122.122`.

There are two ways to do it:

1. Through a DNS provider — Cloudflare, Google Cloud and the like
2. Through your registrar — Namecheap and the like

***

## DNS provider

With Cloudflare you add an A record for IPv4 or an AAAA record for IPv6.

Log in to [your Cloudflare account](https://dash.cloudflare.com/login) and pick the domain. In the left column open `DNS`, then `Records`, and click `Create record`.

Set `Type` to `A` and `Name` to `@`.

<Callout type="idea">
For a subdomain, put its name — `bot`, for instance — in the `Name` field instead.
</Callout>

Enter your server's IP address in the `IPv4 address` field and click `Save`. DNS records take a while to propagate.

<Callout type="idea">
The yellow cloud (domain proxied through Cloudflare) and the grey cloud (domain not proxied) behave differently. If Cloudflare works well in your region, proxying through it is the better choice.
</Callout>

![Cloudflare DNS records](/images/cloudflare-dns.webp)

Other DNS providers look different, but the process is the same.

***

## Nginx configuration

Nginx can run on the same server as the Remnawave panel or on a separate one. Pick the matching tab.

<Tabs items={["Same server","Separate server"]}>
<Tab value="Same server">
Nginx runs on the same server as the Remnawave panel.

<Callout type="error">
Nginx must already be installed and configured on the server that runs the Remnawave panel and the other components.
</Callout>

#### Issue a certificate

Issue a certificate for the Remnashop domain name:

```bash title="Issue certificate"
acme.sh --issue --standalone -d 'BOT_DOMAIN' --key-file /opt/remnawave/nginx/botdomain_privkey.key --fullchain-file /opt/remnawave/nginx/botdomain_fullchain.pem --alpn --tlsport 8443
```

#### Prepare the Nginx configuration

With Nginx already configured, you only add new blocks to the configuration file:

```bash title="Edit nginx.conf"
cd /opt/remnawave/nginx && nano nginx.conf
```

<Callout type="warn">
Replace `BOT_DOMAIN` with your domain name.
</Callout>

<Callout type="error">
Do not replace the existing configuration — only add the Remnashop blocks to it.
</Callout>

Add the `remnashop` upstream at the top of the file:

```nginx title="nginx.conf"
upstream remnawave {
    server remnawave:3000;
}

upstream remnawave-subscription-page {
    server remnawave-subscription-page:3010;
}

upstream remnashop {
    server remnashop:5000;
}
```

Then add a new server block at the bottom of the file:

```nginx title="nginx.conf"
server {
    server_name BOT_DOMAIN;

    listen 443 ssl;
    listen [::]:443 ssl;
    http2 on;

    location /api/v1 {
        proxy_http_version 1.1;
        proxy_pass http://remnashop;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Forwarded-Port $server_port;

        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # SSL Configuration (Mozilla Intermediate Guidelines)
    ssl_protocols          TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384:DHE-RSA-CHACHA20-POLY1305;

    ssl_session_timeout 1d;
    ssl_session_cache shared:MozSSL:10m;
    ssl_session_tickets    off;
    ssl_certificate "/etc/nginx/ssl/botdomain_fullchain.pem";
    ssl_certificate_key "/etc/nginx/ssl/botdomain_privkey.key";
    ssl_trusted_certificate "/etc/nginx/ssl/botdomain_fullchain.pem";

    ssl_stapling           on;
    ssl_stapling_verify    on;
    resolver               1.1.1.1 1.0.0.1 8.8.8.8 8.8.4.4 208.67.222.222 208.67.220.220 valid=60s;
    resolver_timeout       2s;

    # Gzip Compression
    gzip on;
    gzip_vary on;
    gzip_proxied any;
    gzip_comp_level 6;
    gzip_buffers 16 8k;
    gzip_http_version 1.1;
    gzip_min_length 256;
    gzip_types
        application/atom+xml
        application/geo+json
        application/javascript
        application/x-javascript
        application/json
        application/ld+json
        application/manifest+json
        application/rdf+xml
        application/rss+xml
        application/xhtml+xml
        application/xml
        font/eot
        font/otf
        font/ttf
        image/svg+xml
        text/css
        text/javascript
        text/plain
        text/xml;
}
```

#### Mount the new certificate

Update the Nginx `docker-compose.yml` so the new certificate files are mounted:

```bash title="Edit docker-compose.yml"
cd /opt/remnawave/nginx && nano docker-compose.yml
```

```yaml title="docker-compose.yml"
services:
    remnawave-nginx:
        image: nginx:1.28
        container_name: remnawave-nginx
        hostname: remnawave-nginx
        volumes:
            - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
            - ./fullchain.pem:/etc/nginx/ssl/fullchain.pem:ro
            - ./privkey.key:/etc/nginx/ssl/privkey.key:ro
            - ./botdomain_fullchain.pem:/etc/nginx/ssl/botdomain_fullchain.pem:ro
            - ./botdomain_privkey.key:/etc/nginx/ssl/botdomain_privkey.key:ro
        restart: always
        ports:
            - '0.0.0.0:443:443'
        networks:
            - remnawave-network

networks:
    remnawave-network:
        name: remnawave-network
        driver: bridge
        external: true
```

#### Restart the containers

```bash title="Restart the Nginx container"
docker compose down && docker compose up -d && docker compose logs -f
```

```bash title="Restart the Remnashop containers"
cd /opt/remnashop && docker compose down && docker compose up -d && docker compose logs -f
```

<Callout type="idea">
If everything is configured correctly, Remnashop sends a startup notification in Telegram.
</Callout>

#### Issue an SSL certificate

The simplest way is [acme.sh](https://acme.sh/). Install its dependencies first:

```bash title="Install dependencies"
sudo apt-get install cron socat
```

<Callout type="idea">
Any email address works for issuing the certificate, but a valid one is recommended.
</Callout>

Replace `EMAIL` with your address:

```bash title="Install acme.sh"
curl https://get.acme.sh | sh -s email=EMAIL && source ~/.bashrc
```

Create a folder for the certificates:

```bash title="Create directory"
mkdir -p /opt/remnawave/nginx && cd /opt/remnawave/nginx
```

Replace `BOT_DOMAIN` with the domain name the certificate is issued for.

<Callout type="warn">
Do not use the `.ru`, `.su` and `.рф` zones — ZeroSSL does not support them.
</Callout>

```bash title="Issue certificate"
acme.sh --issue --standalone -d 'BOT_DOMAIN' --key-file /opt/remnawave/nginx/privkey.key --fullchain-file /opt/remnawave/nginx/fullchain.pem --alpn --tlsport 8443
```

<Callout type="idea">
Make sure port `8443` is open on the server — it is required for issuing the certificate.
</Callout>

![Successful certificate issuance](/images/issue-cert.webp)

This output confirms the certificate has been issued. `acme.sh` renews it automatically every 60 days, as long as port 8443 stays open and free.

#### Nginx configuration

Create `nginx.conf` in the `/opt/remnawave/nginx` directory:

```bash title="Create nginx.conf"
cd /opt/remnawave/nginx && nano nginx.conf
```

<Callout type="warn">
Replace `REPLACE_WITH_YOUR_DOMAIN` with your domain name.
</Callout>

```nginx title="nginx.conf"
upstream remnashop {
    server remnashop:5000;
}

server {
    server_name REPLACE_WITH_YOUR_DOMAIN;

    listen 443 ssl;
    listen [::]:443 ssl reuseport;
    http2 on;

    location /api/v1 {
        proxy_http_version 1.1;
        proxy_pass http://remnashop;
        proxy_set_header Host $host;

        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header X-Forwarded-Port $server_port;

        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # SSL Configuration (Mozilla Intermediate Guidelines)
    ssl_protocols          TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256:ECDHE-ECDSA-AES256-GCM-SHA384:ECDHE-RSA-AES256-GCM-SHA384:ECDHE-ECDSA-CHACHA20-POLY1305:ECDHE-RSA-CHACHA20-POLY1305:DHE-RSA-AES128-GCM-SHA256:DHE-RSA-AES256-GCM-SHA384:DHE-RSA-CHACHA20-POLY1305;

    ssl_session_timeout 1d;
    ssl_session_cache shared:MozSSL:10m;
    ssl_session_tickets    off;

    gzip_proxied any;
    gzip_comp_level 6;

    gzip_http_version 1.1;
    gzip_min_length 256;

        application/geo+json
        application/javascript
        application/x-javascript
        application/json
        application/ld+json

server {
    listen 443 ssl default_server;

    server_name _;

    ssl_reject_handshake on;
}
```
