Remnashop is reached through a reverse proxy: it terminates TLS for your domain and forwards the bot API to the container.

<Callout type="warn">
Remnashop and its components cannot be served on a sub-path, such as `location /remnashop` or `location /remnawave`.
</Callout>

<Callout type="error">
SSH port forwarding is not supported. Use one of the reverse proxies below.
</Callout>

<Callout type="idea">
You need a registered domain name to continue.
</Callout>

***

## Where the proxy points

The reverse proxy must point at the bot container on the internal address `remnashop:5000` — the Docker service name from `docker-compose.yml`, reachable only inside the container network.

Route: `https://your-domain/api/v1` → `http://remnashop:5000`

***

## Pick a proxy

- [Caddy](/docs/reverse-proxy/caddy) — lightweight, issues SSL certificates automatically, close to zero configuration
- [Nginx](/docs/reverse-proxy/nginx) — the popular option, SSL certificates are issued manually
- [Traefik](/docs/reverse-proxy/traefik) — battle-tested, configured through static and dynamic files
