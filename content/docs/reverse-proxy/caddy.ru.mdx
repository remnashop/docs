В этом руководстве мы используем Caddy в качестве обратного прокси для доступа к Remnashop. Мы направим доменное имя на сервер и настроим Caddy — сертификаты Caddy выпустит самостоятельно.

<Callout type="warn">
Для продолжения вам необходимо иметь зарегистрированное доменное имя.
</Callout>

***

## Направьте домен на сервер

Узнайте IP-адрес вашего сервера. Лучше использовать статический IPv4-адрес.

Теперь направьте доменное имя на этот адрес, например `my-super-panel.com` → `193.122.122.122`.

Это можно сделать двумя способами:

1. Через DNS-провайдера — Cloudflare, Google Cloud и подобные
2. Через регистратора домена — Namecheap и подобные

***

## DNS-провайдер

В Cloudflare нужно добавить запись A для IPv4 или AAAA для IPv6.

Войдите в [аккаунт Cloudflare](https://dash.cloudflare.com/login) и выберите домен. В левой части страницы откройте `DNS`, затем `Records` и нажмите `Create record`.

Установите `Type` в значение `A`, а `Name` — в `@`.

<Callout type="idea">
Для поддомена впишите в поле `Name` его имя — например, `bot`.
</Callout>

Введите IP-адрес сервера в поле `IPv4 address` и нажмите `Save`. Обновление DNS-записей займёт некоторое время.

<Callout type="idea">
Жёлтое облако (домен проксируется через Cloudflare) и серое облако (не проксируется) работают по-разному. Если Cloudflare хорошо работает в вашем регионе, лучше проксировать домен через него.
</Callout>

![DNS-записи в Cloudflare](/images/cloudflare-dns.webp)

У других DNS-провайдеров интерфейс отличается, но процесс тот же.

***

## Настройка Caddy

Caddy может работать на том же сервере, что и панель Remnawave, или на отдельном. Выберите подходящую вкладку.

<Tabs items={["На одном сервере","На отдельном сервере"]}>
<Tab value="На одном сервере">
Caddy работает на том же сервере, что и панель Remnawave.

<Callout type="error">
Caddy уже должен быть установлен и настроен на сервере с панелью Remnawave и остальными компонентами.
</Callout>

#### Подготовка Caddyfile

Если Caddy уже настроен, достаточно добавить новый блок сайта в Caddyfile:

```bash title="Редактирование Caddyfile"
cd /opt/remnawave/caddy && nano Caddyfile
```

<Callout type="warn">
Замените `BOT_DOMAIN` на ваше доменное имя.
</Callout>

<Callout type="error">
Не заменяйте существующую конфигурацию полностью — только добавьте в неё блок сайта для Remnashop.
</Callout>

```text title="Caddyfile"
# ПАНЕЛЬ
https://REPLACE_WITH_YOUR_DOMAIN {
        reverse_proxy * http://remnawave:3000
}
# СТРАНИЦА ПОДПИСОК
https://SUBSCRIPTION_PAGE_DOMAIN {
        reverse_proxy * http://remnawave-subscription-page:3010
}
# REMNASHOP (всё API v1 → remnashop:5000)
https://BOT_DOMAIN {
        reverse_proxy /api/v1/* http://remnashop:5000
}
# CATCH-ALL
:443 {
    tls internal
    respond 204
}
```

#### Перезапуск контейнеров

```bash title="Перезапуск контейнера Caddy"
cd /opt/remnawave/caddy && docker compose down && docker compose up -d && docker compose logs -f
```

```bash title="Перезапуск контейнеров Remnashop"
cd /opt/remnashop && docker compose down && docker compose up -d && docker compose logs -f
```

<Callout type="idea">
Если всё настроено правильно, Remnashop отправит уведомление об успешном запуске в Telegram.
</Callout>
</Tab>

<Tab value="На отдельном сервере">
Caddy работает на другом сервере, отличном от сервера с панелью Remnawave и остальными компонентами.

<Callout type="error">
На этом сервере не должно быть установлено других обратных прокси.
</Callout>

#### Создание Caddyfile

```bash title="Создание Caddyfile"
mkdir -p /opt/remnawave/caddy && cd /opt/remnawave/caddy && nano Caddyfile
```

<Callout type="warn">
Замените `REPLACE_WITH_YOUR_DOMAIN` на ваше доменное имя.
</Callout>

```text title="Caddyfile"
https://REPLACE_WITH_YOUR_DOMAIN {
        reverse_proxy /api/v1/* http://remnashop:5000
}
:443 {
    tls internal
    respond 204
}
```

#### Создание docker-compose.yml

```bash title="Создание docker-compose.yml"
cd /opt/remnawave/caddy && nano docker-compose.yml
```

```yaml title="docker-compose.yml"
services:
    caddy:
        image: caddy:2.9
        container_name: 'caddy'
        hostname: caddy
        restart: always
        ports:
            - '0.0.0.0:443:443'
            - '0.0.0.0:80:80'
        networks:
            - remnawave-network
        volumes:
            - ./Caddyfile:/etc/caddy/Caddyfile
            - caddy-ssl-data:/data
networks:
    remnawave-network:
        name: remnawave-network
        driver: bridge
        external: true
volumes:
    caddy-ssl-data:
        driver: local
        external: false
        name: caddy-ssl-data
```

#### Запуск контейнеров

```bash title="Запуск Caddy"
docker compose up -d && docker compose logs -f -t
```

```bash title="Перезапуск контейнеров Remnashop"
cd /opt/remnashop && docker compose down && docker compose up -d && docker compose logs -f
```

<Callout type="idea">
Если всё настроено правильно, Remnashop отправит уведомление об успешном запуске в Telegram.
</Callout>
</Tab>
