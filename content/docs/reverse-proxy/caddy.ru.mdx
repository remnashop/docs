В этом руководстве мы используем Caddy в качестве обратного прокси для доступа к Remnashop. Мы направим доменное имя на сервер и настроим Caddy — сертификаты Caddy выпустит самостоятельно.

<Callout type="warn">
Для продолжения вам необходимо иметь зарегистрированное доменное имя.
</Callout>

<Section title="Способ установки" description="Где работает Remnashop относительно панели" icon="Split">

<MethodSwitch same="На одном сервере" separate="На разных серверах" />

<Method only="same">

Caddy работает на том же сервере, что и панель Remnawave.

<Callout type="error">
Caddy уже должен быть установлен и настроен на сервере с панелью Remnawave и остальными компонентами.
</Callout>

</Method>

<Method only="separate">

Remnashop работает на отдельном сервере, без панели Remnawave рядом. Caddy ставится на этот же сервер.

<Callout type="error">
На этом сервере не должно быть установлено других обратных прокси.
</Callout>

</Method>

</Section>

<Section title="Направьте домен на сервер" description="A-запись для домена Remnashop" icon="Globe">

Узнайте IP-адрес вашего сервера. Лучше использовать статический IPv4-адрес.

Теперь направьте доменное имя на этот адрес, например `shop.domain.com` → `127.0.0.1`. Это можно сделать через DNS-провайдера (Cloudflare, Google Cloud и подобные) или через регистратора домена (Namecheap и подобные).

В Cloudflare нужно добавить запись A для IPv4 или AAAA для IPv6. Войдите в [аккаунт Cloudflare](https://dash.cloudflare.com/login) и выберите домен. В левой части страницы откройте `DNS`, затем `Records` и нажмите `Create record`.

Установите `Type` в значение `A`, а `Name` — в `@`.

<Callout type="idea">
Для поддомена впишите в поле `Name` его имя — например, `shop`.
</Callout>

Введите IP-адрес сервера в поле `IPv4 address` и нажмите `Save`. Обновление DNS-записей займёт некоторое время.

<Callout type="idea">
Жёлтое облако (домен проксируется через Cloudflare) и серое облако (не проксируется) работают по-разному. Если Cloudflare хорошо работает в вашем регионе, лучше проксировать домен через него.
</Callout>

![DNS-записи в Cloudflare](/images/cloudflare-dns.webp)

У других DNS-провайдеров интерфейс отличается, но процесс тот же.

</Section>

<Section title="Настройка Caddyfile" description="Маршруты к контейнерам Remnashop" icon="FileCode">

<Method only="same">

Если Caddy уже настроен, достаточно добавить новый блок сайта в Caddyfile:

```bash title="Редактирование Caddyfile"
cd /opt/remnawave/caddy && nano Caddyfile
```

<Callout type="error">
Не заменяйте существующую конфигурацию полностью — только добавьте в неё блок сайта для Remnashop.
</Callout>

```text title="Caddyfile"
# ПАНЕЛЬ
https://REPLACE_WITH_YOUR_DOMAIN {
        reverse_proxy * http://remnawave:3000
}
# СТРАНИЦА ПОДПИСОК
https://SUBSCRIPTION_PAGE_DOMAIN {
        reverse_proxy * http://remnawave-subscription-page:3010
}
# REMNASHOP
https://SHOP_DOMAIN {
        encode
        handle /api/v1/telegram {
                reverse_proxy http://remnashop-telegram:5001
        }
        handle {
                reverse_proxy http://remnashop:5000
        }
}
# CATCH-ALL
:443 {
    tls internal
    respond 204
}
```

</Method>

<Method only="separate">

```bash title="Создание Caddyfile"
mkdir -p /opt/remnashop/caddy && cd /opt/remnashop/caddy && nano Caddyfile
```

```text title="Caddyfile"
https://SHOP_DOMAIN {
        encode
        handle /api/v1/telegram {
                reverse_proxy http://remnashop-telegram:5001
        }
        handle {
                reverse_proxy http://remnashop:5000
        }
}
:443 {
    tls internal
    respond 204
}
```

</Method>

<Callout type="warn">
Замените `SHOP_DOMAIN` на домен Remnashop — значение `APP_DOMAIN`.
</Callout>

<Callout type="idea">
Вебхуки Telegram уходят в контейнер `remnashop-telegram`, всё остальное — в `remnashop`. Подробнее — в [обзоре](/ru/docs/reverse-proxy).
</Callout>

</Section>

<Section title="Запуск Caddy" description="Применение конфигурации" icon="Play">

<Method only="same">

```bash title="Перезапуск контейнера Caddy"
cd /opt/remnawave/caddy && docker compose down && docker compose up -d && docker compose logs -f
```

</Method>

<Method only="separate">

```bash title="Создание docker-compose.yml"
cd /opt/remnashop/caddy && nano docker-compose.yml
```

```yaml title="docker-compose.yml"
services:
    caddy:
        image: caddy:2.9
        container_name: 'caddy'
        hostname: caddy
        restart: always
        ports:
            - '0.0.0.0:443:443'
            - '0.0.0.0:80:80'
        networks:
            - remnawave-network
        volumes:
            - ./Caddyfile:/etc/caddy/Caddyfile
            - caddy-ssl-data:/data
networks:
    remnawave-network:
        name: remnawave-network
        driver: bridge
        external: true
volumes:
    caddy-ssl-data:
        driver: local
        external: false
        name: caddy-ssl-data
```

```bash title="Запуск Caddy"
docker compose up -d && docker compose logs -f -t
```

</Method>

</Section>

<Section title="Проверка" description="Панель управления открывается по домену" icon="CircleCheck">
