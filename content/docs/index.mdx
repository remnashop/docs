remnashop — Telegram-бот для продажи VPN-подписок, работающий поверх [Remnawave](https://github.com/remnawave).

Бот берёт на себя весь путь клиента: показывает тарифы, принимает оплату через один из
поддерживаемых шлюзов, выдаёт доступ и напоминает о продлении.
